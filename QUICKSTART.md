# Boss Fitness Website

## Quick Start

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

Open http://localhost:3000

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

## Customization

Edit data files in `src/data/`:
- services.js - Gym programs
- trainers.js - Trainer profiles
- testimonials.js - Member reviews
- pricing.js - Membership plans
- gallery.js - Photo gallery

Update contact info in:
- src/components/Footer.jsx
- src/pages/Contact.jsx
- src/components/WhatsAppButton.jsx
